# VIT Graduation Ceremony Graduation Image Generator
A web-based image generation tool designed to create personalised graduation ceremony images quickly and consistently. Users can upload a student photo, enter the student’s name, select their department, and add a personalised description or quote. The application automatically crops the uploaded photo without distortion, positions all information within a predefined graduation template, and generates a high-quality PNG image ready for download.

The tool provides a simple and user-friendly interface while maintaining consistent image dimensions, formatting, and visual presentation for all students.
